# Wireshark Nedir?

<img src="img/ws.png" alt="alt text" width="280" height="330">

Wireshark, ağ trafiğini gerçek zamanlı olarak yakalayan ve analiz eden açık kaynaklı bir **ağ protokol analizörüdür**. 1998 yılında Gerald Combs tarafından "Ethereal" adıyla geliştirilmiş, 2006'da Wireshark olarak yeniden adlandırılmıştır.
